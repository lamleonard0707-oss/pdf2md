為什麼可以省這麼多？（30 秒讀完）

當你把一份 PDF 交給 AI，它並不是在「讀」你的文件——它會把每一頁轉成一張圖片，再連同該頁的文字一併送入模型。官方文件說明：每頁約消耗 1,500–3,000 個 token。

所以一份 20 頁的文件，你一個問題都還沒問，就已經耗用近 5 萬 token。

轉成文字之後，AI 一樣能看到全部內容，但不必再「拍照」——節省的是那些圖片，而不是把格式整理得更漂亮。

⚠️ 什麼情況不建議轉換：如果你本來就想讓 AI 看圖表、設計稿、掃描件，請直接使用原檔。因為省下的那八成半正正就是圖片，轉換後 AI 便看不到了。

想真正自動化，不必每次都開這個網頁？

如果你正在使用 Claude Code、Cursor 這類 AI Agent，只需安裝一次 MCP，日後把檔案交給它，它就會自動轉換，你什麼都不用做：

pip install markitdown-mcp
claude mcp add markitdown -- markitdown-mcp

安裝後重新啟動 Agent，直接對它說「幫我讀 ~/Downloads/報告.pdf」即可。

想先了解 MarkItDown 是什麼？它是微軟開源的文件轉換工具，本頁的原理與它一致：
🔗 github.com/microsoft/markitdown（官方專案）
🔗 markitdown-mcp（給 AI Agent 用的 MCP 版本）
